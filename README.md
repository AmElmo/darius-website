# darius-website

Public site for [Darius](https://usedarius.com) — the native macOS workspace for AI-native thinking work.

Served via GitHub Pages from `main`. Custom domain: `usedarius.com`.

The full Darius source repo is private; this repo only hosts the marketing site so the domain can run on free GitHub Pages.

## Local preview

```bash
open index.html
```

## Deploy

Push to `main`. GitHub Pages picks it up within ~30 seconds.

## Structure

- `index.html` — the landing page
- `CNAME` — custom domain configuration for GitHub Pages
